1. Introdução à Semântica HTML5

O HTML5 introduz uma série de elementos semânticos que ajudam a estruturar o conteúdo da página de forma mais significativa.

Nesta demonstração, exploraremos alguns desses elementos e como eles podem ser utilizados para melhorar a acessibilidade e a compreensão do conteúdo, como negrito(b) e itálico (i).

2. UC02830 - Elementos Semânticos do HTML5

Esta aula prática serve para demonstrar a utilização dos elementos semânticos do HTML5.

  • <header>: Define o cabeçalho de uma página ou seção.
  • <nav>: Define uma área de navegação.
  • <main>: Define o conteúdo principal da página.
  • <section>: Define uma seção genérica de conteúdo.
  • <article>: Define um artigo independente.
  • <aside>: Define conteúdo complementar, como barras laterais.
  • <footer>: Define o rodapé da página ou seção.

3. Conteúdos e Modularização

Esta seção aborda os conceitos de conteúdo e modularização em HTML5.

Artigo A: A Tag <nav>

A tag <nav> é utilizada para definir uma área de navegação, geralmente contendo links para outras páginas ou seções do site. Ela ajuda os usuários a encontrar informações importantes e facilita a navegação. Aqui temos #introducao, #elementos e #conclusao.

Artigo B: A Tag <section>

A tag <section> é usada para agrupar conteúdo relacionado em uma seção específica da página. Cada seção pode ter seu próprio título e conteúdo, tornando a estrutura da página mais clara e organizada.

Artigo C: A Tag <article>

A tag <article> é utilizada para definir um conteúdo independente que pode ser distribuído ou reutilizado em outros contextos. Cada artigo deve ter um título e pode conter parágrafos, imagens e outros elementos de mídia. Como por exemplo, um artigo de noticia ou um post em um blog.

Artigo D: A Tag <aside>

A tag <aside> é usada para definir conteúdo complementar, como barras laterais, notas ou informações adicionais que não fazem parte do conteúdo principal. Ela ajuda a fornecer contexto adicional sem interromper o fluxo principal da página.

Artigo E: A Tag <footer>

A tag <footer> é utilizada para definir o rodapé de uma página ou seção. Ela geralmente contém informações de copyright, links para políticas de privacidade, contatos e outros elementos relacionados ao final do conteúdo.
