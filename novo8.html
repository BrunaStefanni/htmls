    Introdução à Semântica HTML5

    O HTML5 introduz uma série de elementos semânticos que ajudam a estruturar o conteúdo da página de forma mais significativa.

    Nesta demonstração, exploraremos alguns desses elementos e como eles podem ser utilizados para melhorar a acessibilidade e a compreensão do conteúdo, como negrito(b) e itálico (i).

    UC02830 - Elementos Semânticos do HTML5

    Esta aula prática serve para demonstrar a utilização dos elementos semânticos do HTML5.

    • <header>: Define o cabeçalho de uma página ou seção.
    • <nav>: Define uma área de navegação.
    • <main>: Define o conteúdo principal da página.
    • <section>: Define uma seção genérica de conteúdo.
    • <article>: Define um artigo independente.
    • <aside>: Define conteúdo complementar, como barras laterais.
    • <footer>: Define o rodapé da página ou seção.
