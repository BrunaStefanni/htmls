Tabelas em Tabelas

Nome do Comando Tags Descrição
Tabelas <table> Define uma tabela
Linhas <tr> Define uma linha na tabela
Células <td> Define uma célula na tabela
Cabeçalhos <th> Define um cabeçalho na tabela
border e width border="1" width="100%" Define a borda e a largura da tabela

Tabelas em Mesclagem Colspan

Nome Descrição
HTML Hypertext Markup Language Linguagem de marcação de hipertexto
<colspan> Mesclar células Define o número de colunas que uma célula ocupa. Permite que uma célula se estenda por várias colunas. Mescla lado a lado
<rowspan> Mesclar células Define o número de linhas que uma célula ocupa. Permite que uma célula se estenda por várias linhas. Mescla de cima para baixo

Tabelas em Mesclagem Rowspan

Nome Descrição
Mesclar células
Define o número de linhas que uma célula ocupa. Permite que uma célula se estenda por várias linhas. Mescla de cima para baixo
Exemplo: rowspan="4"
